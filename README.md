# Backend - Audience Query Management API (Node.js / Express / Mongoose)

## Setup
- Copy `.env.example` to `.env` and configure `MONGO_URI`.
- Install dependencies: `npm install`
- Start: `npm run dev` (nodemon) or `npm start`

API endpoints:
- GET /queries
- POST /queries
- PUT /queries/:id
- DELETE /queries/:id
- GET /users
- POST /users
